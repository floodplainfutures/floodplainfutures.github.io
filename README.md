# Yolo Basin — Design Thesis Website

This repository contains the code and assets for my undergraduate design thesis website.

The project explores how **information design and data visualization** can be used to reframe environmental and water-related data—specifically flood, river, and basin systems—so they are more legible, contextual, and meaningful to public audiences.

Rather than treating data as neutral or purely technical, this site uses design as an interpretive layer to surface history, place, and ecological relationships.

---

## Thesis Focus

- Environmental data visualization  
- Flood and water systems (river basins as case study)  
- Design as research and interpretation  
- Public-facing, non-expert accessibility  
- Place-based and historical context  

The work draws from information design, environmental humanities, citizen science, and critical design practices.

---

## Site Contents

The website includes:
- Interactive maps and visualizations using real environmental datasets  
- Historical timelines linking environmental events and design practices  
- Visual literature-review components translated into digital form  
- Experimental layouts that prioritize narrative, context, and place over efficiency
